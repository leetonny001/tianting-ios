# tianting-ios

天听 iOS 客户端（Swift + SwiftUI）。**天听**是自研 IM 平台，替换腾讯 IM（聊天、群聊、聊天室、站内推送）。

天听的 iOS 客户端，UI 和基本功能参考微信。

| | |
|---|---|
| 状态 | 尚未开始，排在工作队列 Q18（M6） |
| 技术 | Swift + SwiftUI，接入 tianting-sdk-swift（Swift Package） |
| 服务端、协议、需求文档 | [tianting-server](https://github.com/leetonny001/tianting-server) |
| 工作队列 / 日报 | tianting-server 的 `docs/process/QUEUE.md`、`docs/reports/daily/` |

UI 规范见 tianting-server 的 `docs/prd/PRD-ui`；iOS 全部 Swift，不用 KMP。
